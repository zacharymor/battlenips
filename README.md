# Battlenips

A one-guess picture game. A stylized drawing sits under a 10×10 grid numbered 1–100. Tap the square you think is hiding the nipple, see hit or miss, then play again.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Production build:

```bash
npm run build
npm start
```

## Deploy

From this directory, after `npx vercel login`:

```bash
npx vercel --prod --yes
```
